Valid and Invalid Strings
Valid Strings (Accepted by the Language)
x
f(x)
g(x)
f(g(x))
g(f(x))
Invalid Strings (Rejected by the Language)
f(x)) → extra closing parenthesis
f((x) → missing closing parenthesis
(x → incomplete expression
f x ) → incorrect structure
g(f(x) → unbalanced parentheses
Notes
Invalid strings demonstrate:

mismatched parentheses
incomplete nesting
structural violations
