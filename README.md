# A Pushdown Automaton for Error Detection in Single-Type Nested Functional Expressions

## Course

CEN 350 – Theory of Computation

## Description

This project focuses on modeling a restricted subset of functional programming expressions using formal language theory.

The goal is to design a Pushdown Automaton (PDA) that detects mismatched parentheses in expressions with single-type nesting.

## Project Components

* Formal language definition
* Context-Free Grammar (CFG)
* Pushdown Automaton (PDA)
* Correctness proof
* Simulation and testing
